What is Helio?

Helio is an open-source Minecraft launcher built primarily around a command-line interface (CLI) and a terminal user interface (TUI) using Rust and Ratatui. It's designed for users who value efficiency, keyboard control, and a lightweight approach to managing Minecraft instances. The launcher is not exclusively for offline or unofficial accounts - account modes are described only where support is confirmed.

Key Features

Easy to Use

Approachable for beginners while remaining powerful for experienced users. Clear workflows and intuitive commands.

Open Source

Fully open source. Inspect, modify, and contribute to the codebase. Community-driven development.

Keyboard-First

Navigate and control everything with your keyboard. Efficient workflow without mouse dependency.

Efficient Design

Resource-conscious and lightweight. Focused on performance without the overhead of heavy GUI frameworks.

Built With

Rust

A systems programming language focused on safety, speed, and concurrency.

Ratatui

A Rust library for building rich terminal user interfaces with a focus on ease of use and flexibility.
