# Contributing to HelioMC Website

Thank you for your interest in contributing to the HelioMC website!

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a new branch for your changes
4. Make your changes
5. Test your changes
6. Submit a pull request

## Guidelines

- Follow the existing code style and patterns
- Use vanilla HTML, CSS, and JavaScript
- No emojis anywhere
- Maintain the black and white color scheme
- Ensure responsive design
- Add proper accessibility attributes
- Test on multiple screen sizes and themes
- No fake functionality or placeholder downloads

## Pull Requests

- Provide a clear description of changes
- Link to related issues if applicable
- Ensure all tests pass
- Update documentation if needed

## Reporting Issues

Please use the GitHub issue templates for bug reports and feature requests.
