# Agent Guidelines

This repository contains the official HelioMC website. When working on this project:

## Code Style
- Use vanilla HTML, CSS, and JavaScript
- Keep code simple and readable
- Use semantic HTML elements
- Follow existing patterns and naming conventions
- No emojis anywhere
- Maintain black and white color scheme

## Design Principles
- Minimal, clean design
- Responsive from mobile to desktop
- Accessible (focus states, ARIA labels where needed)
- Respect reduced motion preferences
- Theme support (System, Light, Dark)
- No fake functionality or placeholder downloads

## Downloads
- Only show real release data from `assets/data/releases.json`
- Never create fake download buttons or URLs
- Show "Coming Soon" when no releases available
- Be transparent about placeholder installation commands

## Files to Edit
- HTML pages in root and subdirectories
- CSS in `assets/css/`
- JavaScript in `assets/js/`
- Configuration in `assets/data/`

## Testing
- Test on different screen sizes
- Test all themes
- Test navigation and links
- Verify no emojis appear
- Check accessibility
